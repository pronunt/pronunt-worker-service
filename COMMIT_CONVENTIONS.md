# Commit Conventions

Use Conventional Commits for this repository.

Format:

`type(scope): short summary`

Examples:

* `feat(worker): consume queue events`
* `fix(normalizer): preserve repository metadata`
* `refactor(service): simplify payload mapping`
* `docs(readme): update local setup steps`
* `chore(deps): bump aio-pika`
* `test(worker): add message handler tests`

Recommended types:

* `feat`
* `fix`
* `refactor`
* `docs`
* `chore`
* `test`
* `ci`
* `build`
